# Project Rules

## 1. No Emojis / Emoticons (STRICT)
- Do NOT use any emojis or emoticons anywhere:
  - In commit messages
  - In GitHub Release titles, descriptions, notes, and tags
  - In README.md and documentation
  - In UI strings, dialogs, modals, and tooltips
- Keep all text strict, technical, clean, and professional.

## 2. Release Distribution Format
- Releases must ALWAYS be published as a single standalone executable (LJTrainer.exe), never as zip archives.

## 3. Git Push & Release Authorization
- NEVER push to git or publish a GitHub release without explicit permission from the user.
